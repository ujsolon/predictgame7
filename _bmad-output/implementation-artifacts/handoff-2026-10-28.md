## 6. Lessons worth keeping (from this stretch)

- **A random gate failure can be memory.** `npm run gate` flaked with timeouts and `spawn UNKNOWN` when free RAM was about 120–230 MB, and passed with `npx vitest run --maxWorkers=2`. Close apps and retry; **never `--no-verify`**.
- **Probing the prerendered site:**
  1. `npm run build && npm run og:cards && npm run prerender`;
  2. **`npx vite preview`** (not `npm run preview`, which rebuilds and wipes the og and prerender output);
  3. then the probes.

  The deep-link probe takes several minutes.
- **Deploys:** `npm run deploy` **alone** (predeploy already runs the gate). Only on the owner's request.
- **Migrations:** the agent writes and rehearses them; **the owner applies them** with `npx supabase db push`. Bump the rehearsal's `COVERED_THROUGH` in the same commit as a new migration.
- **UI stories:** the owner sees a preview (mockup or screenshots) before the spec freezes.
